## What is Obsidian?

Obsidian is a desktop and mobile note taking app that stores everything as plain Markdown files in a folder on your device. No account is required and no server is involved in the core product. You point the app at a folder, called a vault, and every note is a text file you can open in any other editor, back up with any tool and keep for as long as you like. Links between notes use double bracket syntax, and the app tracks backlinks so each note shows every other note that references it. A graph view draws the whole vault as connected nodes.

The app is free for personal use and, following a licensing change, also free for commercial use. Paid add ons are optional: Obsidian Sync provides end to end encrypted synchronisation between devices, and Obsidian Publish turns a set of notes into a public website. The plugin ecosystem is the other half of the product. Community plugins add Kanban boards, calendars, spaced repetition, task management, database style tables through Dataview and the newer Bases feature, and AI assistants that talk to whichever model provider you configure. Canvas, a built in feature, gives you an infinite whiteboard for arranging notes and cards.

## Where it shines

Ownership and longevity are the point. Your notes are files, so nothing is locked in a vendor database, nothing stops working if the company disappears, and version control with Git is a normal workflow rather than a hack. For researchers, writers and engineers who expect to keep notes for decades, that is the deciding factor.

Speed is excellent. The app opens instantly, search across tens of thousands of notes is near immediate, and everything works fully offline. Mobile apps on iOS and Android run the same vault and most of the same plugins.

The linking model rewards long term use. Daily notes, backlinks and unlinked mention detection make it easy to see how ideas connect months later. With Dataview or Bases, a folder of notes with frontmatter properties becomes a queryable table, which gets you much of what people use Notion databases for without leaving Markdown.

The plugin community is large and active, and because the app is built on web technology, writing your own plugin is approachable for anyone who knows JavaScript.

## Where it falls short

Obsidian is a single player tool at heart. Two people cannot edit the same note at the same time, there are no comments or mentions, and sharing a vault means either Sync with shared vaults on a paid plan or a Git repository. Teams that need a shared wiki with permissions should look at [Notion](/tools/notion/) or [Confluence](/tools/confluence/), and people who want a polished collaborative editor with a similar local first feel should consider [Craft](/tools/craft/).

Setup is on you. Out of the box the app is deliberately minimal, and getting to a comfortable configuration usually means installing a dozen plugins, each maintained by a volunteer who may stop updating it. Plugin breakage after app updates is a real maintenance cost, and a heavily customised vault is hard to hand to a colleague.

There is no built in AI. Everything AI related comes from plugins that need your own API key, and quality varies widely. Tables are plain Markdown, so anything beyond a simple grid is awkward to edit, and there is no web version for a machine where you cannot install software.

## Conclusion

Obsidian is the best personal knowledge base available, and the local Markdown foundation makes it the safest place to keep notes you care about. The free core app and optional Sync are hard to argue with on price. It is not a team wiki and it is not a project manager, so companies choosing a shared tool should look elsewhere while letting individual staff keep their own vaults.
